# 立方体贴图接缝审计

从六面签名坐标系配对同一条物理边，并产出方向归一后的像素误差证据。 这是处理合成数据的离线参考应用，不依赖网络、数据库服务或第三方库。

```sh
python3 -B -m cubeseams examples/demo.json
python3 -B examples/smoke.py
```

需要 Python 3.9+。传入任意匹配契约的 UTF-8 JSON 文件，输出 JSON 写到标准输出；非法输入使用退出码 2，诊断写到标准错误。业务上发现冲突仍会产生完整分析结果。完整测试套件暂缓；随仓冒烟样例从实际命令行入口验证有效结果与输入拒绝。

每面含右轴、下轴、法向及灰度数组，右轴叉乘下轴等于法向；阈值是绝对灰度差的上限。 详见 [项目说明](PROJECT_SPEC.md) 和 [输入样例](examples/demo.json)。
